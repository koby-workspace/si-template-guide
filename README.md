# SI 템플릿 만들기 — 따라 하며 배우는 React 업무 시스템

빈 폴더에서 시작해, 어느 SI 프로젝트에나 가져갈 수 있는 **업무 시스템 프론트엔드 템플릿**을 직접 만들어 보는 가이드입니다.
모든 코드가 순서대로 들어 있고, 원리·팁·주의사항·단축키를 쓰는 순간에 하나씩 설명합니다.

> ✅ **이 가이드의 코드는 전부 실행해서 검증했습니다.** 문서의 코드 블록을 프로그램으로 그대로 뽑아 빈 폴더에 순서대로 적용하고,
> **모든 커밋 지점(총 106개)에서 타입 검사**를, 각 Part 끝에서 빌드·ESLint·Prettier 검사를 통과하는 것을 확인했습니다.
> 주요 기능은 실제 브라우저로 클릭해 가며 동작도 확인했습니다. (검증일 2026-11-07)

## 어떻게 진행하나요?

1. **[Part 0](part-00-before-you-start.md)부터 읽으세요.** 표식(📄 ✏️ ▶️ ✅)의 뜻과 진행 리듬을 설명합니다.
2. **하루 Step 1~3개.** 한 Step은 10~30분입니다. 멈출 때는 커밋 지점에서 멈춥니다.
3. **○ 표시 Step과 Part 13은 골라도 됩니다.** 지치면 건너뛰고, 재미있는 것부터 하세요.
4. **🏁 마일스톤마다 화면을 캡처하세요.** 나중에 나란히 보면 얼마나 왔는지 보입니다.
