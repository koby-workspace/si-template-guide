## 터미널 (PowerShell)

| 입력                 | 하는 일                                         |
| -------------------- | ----------------------------------------------- |
| `Ctrl+C`             | 실행 중인 명령(개발 서버 등) 멈추기             |
| `↑`                  | 이전 명령 다시 불러오기                         |
| `Tab`                | 파일·폴더 이름 자동 완성                        |
| `cls`                | 화면 지우기                                     |

| `git restore <파일>` | 마지막 커밋 상태로 되돌리기 (실험 후 원복)      |
